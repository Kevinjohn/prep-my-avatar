Step 17: Export dataset

Export creates a standard training package from the images currently marked kept. It does not include rejected or undecided images.

Before you begin

Finish curation and captions first. An export can be useful even if you never train inside Prep My Avatar.

Do this

  1. Open Export dataset in the dataset step navigator. Its URL ends in /export.
  2. Check the kept count beside Export ZIP.
  3. Select Export ZIP.
  4. Choose a destination folder if your browser asks.
  5. Wait for the download to finish, then open the ZIP to verify it contains image files and matching .txt caption files.
  6. Keep _prep_my_avatar_manifest.json. Training tools can ignore it, but it records the source mix, coverage, and provenance.
  7. Select Continue to Train a LoRA.

An export ZIP is a training package, not a complete backup of the project. The final guide step explains the separate Backup action.

Reviewed hosted person pack

For a character dataset, choose Prepare hosted export. No local trainer, service credentials or network access is needed.

  1. Confirm the subject, trigger, source rights, consent and intended publication scope.
  2. Select training, reference and evaluation roles. Keep evaluation families and burst groups separate. Give references a purpose and order.
  3. Preview each selected role. Adjust the square training crop and check face/body content; wider references and evaluation photos retain their own framing.
  4. Review the final caption beside the exact derivative, then approve each pair. Crop, caption or relevant setting changes require renewed approval. Master captions and originals are preserved.
  5. Download and retain the complete private revision with manifest.json, recipe.json, references/ and evaluation/. Only krea_training.zip is the trainer upload archive.

The browser saves draft selections, but approvals must be repeated when reopening. Export makes no provider request and grants no upload or spending permission. See the manual pilot kit for the reference baseline, private records and silent-video review. Ordinary Export ZIP and Backup remain separate actions.

Retain attempts and returned assets

Open Private asset bank after creating a reviewed export. The reference-only recipe prepares generation references and optional held-out evaluation photos without requiring training images.

Record a manual still, training or video attempt with its actual recipe, ordered references, prompt and seed. Update outcomes and costs, retaining failures and uncertain outcomes too. Import returned images, clips, weights and configuration locally, then review each output separately. Accepted stills can become first frames for video attempts.

FFprobe checks actual video/audio streams when installed. FFmpeg can create a separate silent derivative while preserving the original. Neither operation proves likeness or accepts a clip automatically.

Download the dedicated private bank archive for records, files and linked export evidence. Ordinary dataset Backup does not include this bank. These local actions perform no provider upload, request or charge.

You are finished when

A ZIP file exists in your chosen download folder and its image/text pairs match the kept set. If export is your goal, skip the optional training, checkpoint-review, and Studio work in Steps 18–20, then continue to Step 21 to back up the dataset.
